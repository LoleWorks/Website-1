# ScutDent — Dental Clinic Landing Page

A modern, animated landing page for **ScutDent**, a dental clinic in Chișinău, Moldova.
Built with React, Vite, Tailwind CSS and Framer Motion.

## Highlights

- Hero with animated blobs, floating info cards and a live rating badge
- Trust bar with clinic stats
- Services grid with hover glow & iconography
- About section with dynamic info tiles
- Auto-rotating, swipeable patient testimonials
- Booking form with success state
- Fully responsive, accessible and ready for real traffic

## Getting started

```bash
npm install
npm run dev
```

Open <http://localhost:5173> in your browser.

## Build

```bash
npm run build
npm run preview
```

## Stack

- React 18 + Vite 5
- Tailwind CSS 3
- Framer Motion 11
- Lucide icon set
